# CloudLab Works

Community health files and security policies for [CloudLab Works](https://cloudlabworks.dev) and its open
source projects on GitHub.

## Security policies

- [Security baseline](policies/security-baseline.md): minimum security settings for CloudLab Works accounts,
  devices, code, dependencies and releases.
- [Security and AI governance policy](policies/security-and-ai-governance-policy.md): roles, the policy set,
  reviews, exceptions, legal tracking, acceptable use of oak-events and internal use of AI.
- [Incident response plan](policies/incident-response-plan.md): how vulnerabilities and incidents are
  reported, rated, fixed, disclosed and recorded.

Product documents for oak-events (threat model, model card, data flow, SBOM) are in
[cloudlabworks/oak-events/docs](https://github.com/cloudlabworks/oak-events/tree/main/docs).

## Reporting a vulnerability

Use "Report a vulnerability" on the affected repository's Security tab, or the contact in
<https://cloudlabworks.dev/.well-known/security.txt>. Please do not open a public issue.
